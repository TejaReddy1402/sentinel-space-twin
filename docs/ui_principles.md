# UI principles

The interface should not be a fake command centre.

It should be an evidence cockpit:

1. Map at the centre.
2. Before/after images next to the map.
3. Quality score visible at all times.
4. Timestamps always visible.
5. Cloud cover always visible.
6. Change polygons must be clickable.
7. Every AI claim should link back to source image/layer.
8. Every panel should state whether a claim is visible, inferred or not possible.

Recommended screens:

- AOI explorer
- Scene timeline
- Evidence comparison
- Change detection layer
- Visibility matrix
- VLM analyst report
- Live movement fusion layer
- Alert builder
